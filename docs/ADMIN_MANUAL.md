## 1. 로그인

1. 홈페이지 오른쪽 위 **LOGIN** 을 누르고 관리자 계정으로 로그인합니다.
2. 로그인하면 메뉴에 **ADMIN** 이 나타납니다. 눌러서 관리자 페이지로 들어갑니다.
3. 관리자 페이지 위쪽에 **11개 탭**이 있습니다. 이 안내서는 그 탭 순서대로 설명합니다.
4. 주소를 직접 쳐서 들어가려면 `홈페이지주소/admin` 입니다.

> **주의** — 관리자 계정이 아닌 일반 회원으로 로그인하면 관리자 페이지가 보이지 않고
> 홈으로 되돌아갑니다. 잘못 들어간 것이 아니라 정상 동작입니다.

## 2. 단지 관리

관리 중인 아파트·단지 목록을 다루는 곳입니다. 탭 **「단지 관리」**.

1. **추가** — 오른쪽 위 「새 단지 등록」 → 단지명·지역·세대수 등을 넣고 저장합니다.
2. **수정** — 목록에서 해당 단지의 「수정」 → 값을 고치고 「변경 저장」.
3. **현재/과거 전환** — 계약이 끝난 단지는 「과거로」 를 누릅니다. 지우지 않고 과거 목록으로 옮깁니다.
4. **삭제** — 잘못 등록한 경우에만 씁니다. 지운 뒤에도 「복구 이력」에서 되살릴 수 있습니다.

> **주의 1** — 단지명을 바꿔도 그 단지의 **인터넷 주소(링크)는 바뀌지 않습니다.**
> 기존에 공유된 링크와 검색 결과가 깨지지 않도록 일부러 그렇게 만들었습니다.
>
> **주의 2** — 단지를 추가·삭제해도 메인 화면의 **「관리 단지 200+」 같은 표기값은
> 자동으로 바뀌지 않습니다.** 그 숫자는 3번(회사 정보·수치 수정)에서 따로 고칩니다.

## 3. 회사 정보·수치 수정

홈페이지 곳곳의 글과 숫자를 고치는 곳입니다. 탭 **「사이트 설정」**.

한 화면에 여러 묶음이 세로로 놓여 있고, **묶음마다 저장 버튼이 따로** 있습니다.
고친 묶음의 저장 버튼만 누르면 됩니다.

| 고치고 싶은 것 | 묶음 이름 |
|---|---|
| 주소·전화·팩스·이메일·영업시간 | 연락처 |
| 상호·대표자·자본금·사업자번호 | 회사 기본 정보 |
| 대표 인사말 | 대표 인사말 |
| 메인 화면 숫자 4개 | 메인 카운터 |
| 「관리 단지 200+」 같은 표기값 | 마케팅 표기값(STATS) |
| 사업영역 5종 이름·설명 | 사업영역 |
| 연혁 · 조직도 · 인허가 · 자격증 · 협력업체 | 각 같은 이름의 묶음 |

> **주의 1** — 「마케팅 표기값」 화면에는 **실제 등록된 단지 수**와 **표기하는 숫자**가
> 나란히 보입니다. 두 숫자가 다른 것은 잘못이 아니라 의도된 것입니다(홍보 표기).
> 크게 벌어지면 화면에 안내가 뜨니 그때 표기값을 손보시면 됩니다.
>
> **주의 2** — 저장하는 사이에 다른 관리자가 먼저 저장했다면 **덮어쓰지 않고 멈춥니다.**
> 「다른 관리자가 먼저 저장했습니다」 안내가 뜨면 새로고침한 뒤 다시 고쳐 주세요.

## 4. 이미지·히어로 교체

### 사진 하나 바꾸기

각 편집 화면의 사진 항목에 **「파일 선택」 업로드 칸**이 있습니다.
파일을 고르면 바로 올라가고, 화면에 미리보기가 나타납니다. 그 뒤 **저장**을 눌러야 반영됩니다.

### 메인 화면 큰 영상·사진(히어로) 바꾸기

1. 탭 **「사이트 설정」** → **「메인 히어로 슬라이드」** 묶음으로 갑니다.
2. 슬라이드마다 영상 또는 사진을 교체할 수 있습니다.
3. 순서도 위·아래 화살표로 바꿉니다.
4. 저장을 누르면 메인 화면에 바로 반영됩니다.

> **주의** — 영상은 용량이 큽니다. **한 파일 20MB 이하**를 권합니다.
> 너무 크면 방문자 쪽에서 재생이 늦어집니다.

## 5. 섹션 표시·순서

한 페이지를 이루는 **영역(섹션)** 을 켜고 끄고 위아래로 옮깁니다. 탭 **「섹션 구성」**.

1. 위쪽에서 페이지를 고릅니다 (메인 · 회사소개 · 사업영역 …).
2. 그 페이지의 영역 목록이 나옵니다.
3. **눈 아이콘**으로 켜고 끄고, **↑ ↓ 화살표**로 순서를 바꿉니다.
4. 바꾸는 즉시 반영됩니다. 새 탭에서 해당 페이지를 열어 확인해 보세요.

> **주의** — 「필수」 표시가 붙은 영역은 끌 수 없습니다. 그 영역이 없으면 페이지가
> 빈 화면이 되기 때문입니다.

## 6. 메뉴·페이지 공개

### 메뉴 이름·순서·숨김 — 탭 **「메뉴 구성」**

1. 상단 메뉴와 하단(푸터) 메뉴가 각각 목록으로 나옵니다.
2. **이름**을 고쳐 저장하면 화면 메뉴 글자가 바뀝니다.
3. **↑ ↓** 로 순서를, **표시/숨김** 으로 노출 여부를 바꿉니다.

> **주의 1** — 메뉴 **추가·삭제는 없습니다.** 안 쓰는 메뉴는 「숨김」으로 두시면 됩니다.
> **주의 2** — 「사업영역」 아래 5개 항목은 여기서 안 고칩니다.
> 「사이트 설정 → 사업영역」에서 고치면 메뉴가 따라 바뀝니다.

### 페이지 공개·비공개 — 탭 **「페이지 공개」**

각 페이지 오른쪽 버튼으로 공개/비공개를 바꿉니다. **비공개로 돌리면 동시에 세 가지가 일어납니다.**

- 방문자에게는 **없는 페이지(404)** 로 보입니다
- 상단·하단 **메뉴에서 빠집니다**
- **검색엔진용 사이트맵에서도 빠집니다**

관리자는 비공개 페이지도 그대로 열어볼 수 있고, 화면 위에 안내 띠가 뜹니다.

> **주의 1** — **메인 화면은 비공개로 못 바꿉니다**(「공개 고정」 표시). 메인을 닫으면
> 사이트 전체가 안 열리기 때문입니다.
>
> **주의 2** — **하위 페이지까지 같이 닫히지는 않습니다.** 예를 들어 「사업영역」을 비공개로
> 해도 「사업영역 → 주택관리」 같은 하위 상세 페이지는 그대로 열립니다. 필요하면 하위
> 페이지도 각각 비공개로 바꿔 주세요.

## 7. 채용 공고

탭 **「채용 공고」**.

1. **등록** — 「새 공고 작성」 → 직무명·모집 지역·마감일·주요 업무 등을 넣고 저장합니다.
   - 마감일을 **비워 두면 「상시채용」** 으로 표시됩니다.
   - 주요 업무·자격 요건은 **한 줄에 하나씩** 적으면 목록으로 정리됩니다.
2. **수정** — 목록에서 「수정」.
3. **마감** — 「마감 처리」 를 누르면 채용 페이지에서 즉시 내려갑니다.
   다시 올리려면 「다시 게시」.
4. **삭제** — 완전히 지웁니다. 기록을 남기고 싶으면 삭제 대신 「마감 처리」를 쓰세요.

> **주의 1** — **마감일이 지나면 자동으로 채용 페이지에서 빠집니다.** 따로 내리지 않으셔도 됩니다.
> 관리자 화면에는 「마감」 상태로 그대로 남습니다.
>
> **주의 2** — 마감일이 지난 공고는 「다시 게시」만 눌러서는 안 보입니다.
> 「수정」에서 마감일을 미래 날짜로 바꾸거나 비워 주세요. 화면에도 같은 안내가 뜹니다.

## 8. 게시판과 공지 고정

### 글 쓰기 — 탭 **「소식 관리」**

공지사항 · 갤러리 · 단지소식 · 자료실 4개 게시판에 글을 올리고 고치고 지웁니다.

1. 게시판을 고릅니다.
2. 「새 글 작성」 → 제목·내용을 넣고, 필요하면 사진·문서를 첨부합니다.
3. 갤러리는 사진이, 자료실은 문서가 **반드시 하나 이상** 있어야 저장됩니다.

### 공지 상단 고정

글 목록에서 **「상단 고정」** 버튼을 누르면 그 글이 목록 맨 위로 올라가고 「공지」 표시가 붙습니다.
해제하려면 같은 자리의 **「고정 해제」** 를 누릅니다.

### 게시판 이름·설명 바꾸기 — 탭 **「게시판 카테고리」**

게시판 4종의 **이름**과 **설명 문구**를 바꿉니다. 비워 두면 원래 문구(회색 글씨)가 쓰입니다.
바꾼 이름은 게시판 페이지와 관리자 화면 양쪽에 함께 반영됩니다.

> **주의 1** — **게시판을 새로 만들거나 지울 수는 없습니다.** 기존 글이 어느 게시판에
> 속하는지와 첨부 규칙이 함께 묶여 있어서입니다.
>
> **주의 2** — 상단 메뉴 「소식」 안에 보이는 **순서와 숨김**은 여기가 아니라
> 「메뉴 구성」에서 바꿉니다.

## 9. 실수했을 때 복원

탭 **「복구 이력」**.

**단지 정보**와 **사이트 설정**은 저장할 때마다 **직전 값이 자동으로 보관**됩니다.

1. 「복구 이력」 탭을 엽니다. 최근에 바뀐 항목이 위에서부터 나옵니다.
2. 되돌리고 싶은 항목의 **「이력 보기」** 를 누릅니다.
3. **저장 시각**과 **편집자**가 적힌 목록이 나옵니다. 원하는 시점의 **「이 시점으로 복원」** 을 누릅니다.
4. 확인 창에서 「확인」 을 누르면 그 시점 값으로 돌아갑니다.

> **되돌리기를 다시 되돌릴 수 있습니다.** 복원하기 직전 값도 이력에 함께 보관되므로,
> 복원해 보고 마음에 안 들면 한 번 더 복원해서 원래대로 돌아갈 수 있습니다.
>
> **주의 1** — 항목마다 **최근 20개**까지만 보관됩니다. 그보다 오래된 것은 자동으로 지워집니다.
> **주의 2** — 게시판 글·채용 공고는 이 이력에 들어가지 않습니다. 지우기 전에 한 번 더 확인해 주세요.
> **주의 3** — 실수로 **지운 단지**도 여기서 되살릴 수 있습니다. 「삭제됨」 표시가 붙어 있습니다.

## 10. 자주 묻는 것

**Q. 고쳤는데 홈페이지에 안 보여요.**
저장 버튼을 눌렀는지 먼저 확인하고, 보는 쪽 화면을 새로고침(F5)해 보세요.
그래도 안 보이면 브라우저 캐시 때문일 수 있으니 `Ctrl + F5` 로 강제 새로고침해 주세요.

**Q. 「관리 단지 200+」 숫자를 어디서 고치나요?**
「사이트 설정 → 마케팅 표기값(STATS)」 입니다. 단지를 추가해도 자동으로 안 바뀝니다.

**Q. 메뉴를 하나 더 만들고 싶어요.**
이번 작업 범위에는 메뉴·페이지 **추가**가 들어 있지 않습니다. 필요하시면 별도로 말씀해 주세요.

**Q. 사진 용량 제한이 있나요?**
사진은 한 장 5MB, 문서는 10MB, 히어로 영상은 20MB 정도를 권합니다.

**Q. 실수로 큰 걸 바꿔서 사이트가 이상해졌어요.**
「복구 이력」에서 되돌리시면 됩니다(9번). 그래도 해결이 안 되면 연락 주세요 —
사이트 전체를 배포 이전 상태로 되돌리는 수단이 따로 준비돼 있습니다.
