## 2. 별도 안건 (계약 범위 밖 — 결정 대기)

아래는 **이번 계약에 포함되지 않은 사항**이다. 필요하면 별도로 말씀해 주시면 된다.

| # | 안건 | 현재 상태 | 진행하려면 |
|---|------|-----------|------------|
| 1 | **Pretendard 미적용** | 라이브는 **처음부터 Pretendard 를 받은 적이 없다**(배포 CSS 번들에 `pretendard` 문자열 0회). `--font-sans` 의 다음 후보로 렌더돼 왔다 | 적용하면 **전 페이지 렌더가 변한다.** 회귀 베이스라인 28장을 전부 다시 세워야 한다 |
| 2 | **`/images/hero` 미사용 자산 37MB** | 실제 배포에는 alias(`video-0X.mp4`·`slide-0X.png`)만 포함되고 원본은 `.vercelignore` 로 제외돼 있다. 저장소에는 남아 있다 | 원본 보존이 필요 없다고 판단되면 삭제. 배포 용량에는 이미 영향 없음 |
| 3 | **미참조 Storage 객체** | 이미지를 교체하면 이전 객체가 Storage 에 남는다. **의도적으로 지우지 않는다** — 되돌리기 수단이기 때문 | 장기적으로 쌓이면 정리 배치가 필요 |
| 4 | **`businessGallery` 공유 구조** | 사업영역 5종이 갤러리 사진 묶음을 공유한다. 한 영역에서 사진을 바꾸면 다른 영역에도 반영된다 | 영역별로 분리하려면 데이터 구조 변경 필요 |
| 5 | **비공개 연쇄 없음** | 부모 페이지를 비공개로 해도 하위 상세는 닫히지 않는다(`/business` → `/business/facility`, `/cases` → `/cases/[slug]` 등). **의도된 동작** — `/business` 하나를 잘못 꺼서 하위 5종이 한꺼번에 사라지는 사고 경로를 만들지 않기 위함 | 필요하면 레지스트리에 부모-자식 관계 1줄 추가로 확장 가능 |
| 6 | **메뉴·페이지 신규 생성 없음** | 계약 문구가 「이름 변경 · 순서 조정 · 표시·숨김」 / 「공개·비공개 전환」까지다. 숨김이 삭제 대용이고, 추가는 가리킬 페이지가 있어야 한다 | 페이지 신규 생성 기능부터 필요 |
| 7 | **게시판 추가·삭제 없음** | 게시판 종류가 기존 글(`posts.board_type`)·첨부 정책·라우트에 묶여 있다. 늘리면 기존 글이 함께 영향을 받는다 | 스키마·라우트·첨부 정책 확장 필요 |
| 8 | **낙관적 잠금 적용 범위** | 단지·사이트 설정에는 동시 편집 방어(E-8)가 걸려 있다. **채용 공고·게시판 글에는 없다** — 기존 코드 그대로 두었다 | 필요하면 같은 방식으로 확장 |

| E-14 | 루트 레이아웃 메뉴 조회로 전 페이지 쿼리 1회 추가 | **해소** | `content:nav` 태그 캐시(revalidate 1h)로 사실상 0회 |

> **배포 후 확인 결과 (2026-08-26)** — 태그 무효화는 **페이지 404 와 메뉴 제외에는 즉시(1초) 반영되지만
> `/sitemap.xml` 에는 전파되지 않는다.** 로컬에서는 전파됐으나 Vercel 의 정적 라우트 캐시(`revalidate 1h`)에는
> 닿지 않는다. **실피해는 죽은 링크가 최대 1시간 sitemap 에 남는 것뿐**이고, 그 URL 로 들어와도 404 는 즉시 걸린다.
> 조치 후보는 `togglePagePublished` 에 `revalidatePath("/sitemap.xml")` 1줄 추가(경로 1개 지정이라 E-12 원칙에 어긋나지 않음).
> 효과는 **재배포 후 라이브에서만** 검증할 수 있다. **결정 대기 중.**
