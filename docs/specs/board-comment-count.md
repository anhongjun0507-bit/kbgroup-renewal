# 자유게시판 목록 댓글 수 표시 (2026-10-29 원문)

[목표]
KB개발 사이트(kbgroup.kr) 자유게시판 목록에서 게시글 제목 옆에 댓글 수를 표시한다.
예) 마음의노래 (3)
지금 만드는 것: 클라이언트 담당자가 직접 운영하는 기업 사이트의 게시판. 방문자가 목록만 보고 활발한 글을 알아볼 수 있게 한다.

명세 원문은 docs/specs/board-comment-count.md 에 저장하고, 코드와 다른 점부터 보고한 뒤 시작해.
먼저 확인할 것:
- "자유게시판"이 어느 게시판인지. 현재 board_type 4종(공지·갤러리·단지소식·자료실) 중 이름을 바꿔 쓰는 것인지(site_settings.boardCategories), 별도 게시판인지
- 댓글 테이블·관계가 실제로 있는지, 삭제·숨김 처리 컬럼이 무엇인지
- 댓글이 있는 게시판이 하나뿐이면 그 게시판에만 적용. 여러 개면 댓글 기능이 있는 게시판 전부에 적용

[구현 방침]
- 댓글 수는 목록 조회 1번에 함께 가져온다. 글마다 따로 세는 쿼리(N+1)는 쓰지 않는다. 목록이 30건이면 쿼리도 30번 늘어나기 때문.
- 1순위: PostgREST 임베디드 카운트(comments(count))로 삭제·숨김 댓글을 뺀 수를 가져온다. 필터가 카운트에 적용되지 않으면 집계 뷰 또는 RPC로 바꾼다. 카운트 컬럼+트리거 방식은 쓰지 않는다(이 규모에 과함).
- 0개면 표시하지 않는다. 1개 이상일 때만 " (N)".
- 표기는 제목과 같은 줄, 제목보다 한 단계 옅은 색. 기존 목록 디자인 토큰 안에서 고른다.
- 제목이 길어 말줄임될 때 댓글 수는 잘리지 않게 한다(제목만 truncate, 숫자는 밖에 둔다). 모바일 390px에서 확인.
- 비밀글·관리자 전용 글은 목록에 원래 보이던 규칙 그대로. 댓글 수만 더한다.
- 댓글 작성·삭제 Server Action에서 해당 게시판 목록 캐시 태그를 updateTag로 무효화해, 목록 숫자가 즉시 바뀌게 한다. 광역 revalidatePath("/", "layout") 금지.

[합격 기준]
- 댓글 3개 달린 글이 목록에 "제목 (3)"으로 보인다 — 캡처로 증명
- 댓글 0개 글은 숫자 없음
- 댓글 1개 추가 → 새로고침 없이 재진입 시 (4), 삭제 → (3)으로 즉시 반영. 프로덕션 배포 후 라이브에서 실측(로컬 통과만으로는 PASS 처리하지 않는다)
- 삭제·숨김 댓글은 수에서 빠진다
- 목록 조회 쿼리 수가 변경 전과 같다(로그로 증명)
- 긴 제목 + 댓글 수가 데스크탑 1440·모바일 390에서 잘리지 않음 — 캡처 2장
- tsc·eslint 신규 0건, 빌드 EXIT=0, 라우트 표 무변화
- 다른 게시판 목록 SSR 가시 텍스트 diff 0줄

[범위 밖]
- 게시판 구조·스키마 변경, 댓글 기능 자체 수정, 관리자 CMS 화면 변경은 하지 않는다. 이번 요청은 목록 표시 하나다.
- 상세 페이지·메인 페이지 노출은 손대지 않는다.
- 범위 밖 리팩터·새 파일 만들지 않는다. 검증용 임시 파일·테스트 댓글은 끝에 지운다.
